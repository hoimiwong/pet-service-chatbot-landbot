# Pet Service Chatbot (Landbot)

## Description
Developed an interactive chatbot to handle customer inquiries and booking requests for pet services.

## Demo Link
https://app.landbot.io/gui/bot/3306776/builder

## Key Features
- Implemented rule-based chatbot using decision tree logic  
- Supported grooming appointment booking system  
- Provided product recommendations based on pet type  
- Designed FAQ system for common customer inquiries  
- Created user-friendly conversational flow  

## Technologies Used
- Landbot  
- Rule-based AI (IF-THEN logic)  
- Google Sheets (data storage)  

## Project Purpose
This project demonstrates the application of chatbot design, decision tree logic, and automation in improving customer service efficiency.

## Skills Gained
- Chatbot development and conversation design  
- Decision tree logic and rule-based systems  
- User interaction and UX design  
- Data handling with Google Sheets
